# Password Generator

A simple, secure password generator built with React + TypeScript + Vite.

## Features

- Generate secure passwords (8-32 characters)
- Customizable character types: uppercase, lowercase, numbers, symbols
- Password strength indicator
- Copy to clipboard with one click

## Tech Stack

- **Runtime**: Bun
- **Frontend**: React 19 + TypeScript
- **Build**: Vite 8
- **Styling**: CSS Modules

## Getting Started

```bash
# Install dependencies
bun install

# Start development server
bun run dev

# Build for production
bun run build

# Preview production build
bun run preview
```
